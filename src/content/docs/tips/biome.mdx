Quickly configure Biome for your Astro project

<Aside>
Biome v2 supports linting and formatting `.astro` files (including component scripts, styles, and templates) via `html.experimentalFullSupportEnabled` and the `astro` linter domain. If you prefer not to enable experimental HTML formatting yet, you can combine Biome with [Prettier](/tips/prettier) for `.astro` templates.
</Aside>

<Steps>

1. Install Biome using your preferred package manager:
    <Tabs syncKey="biome">
      <TabItem label="npm" icon="seti:npm">
        ```sh
        npm install --save-dev --save-exact @biomejs/biome
        ```
      </TabItem>
      <TabItem label="pnpm" icon="pnpm">
        ```sh
        pnpm add --save-dev --save-exact @biomejs/biome
        ```
      </TabItem>
      <TabItem label="yarn" icon="seti:yarn">
        ```sh
        yarn add --dev --exact @biomejs/biome
        ```
      </TabItem>
      <TabItem label="bun" icon="bun">
        ```sh
        bun add --dev --exact @biomejs/biome
        ```
      </TabItem>
    </Tabs>

2. Next, create the Biome configuration:

    <Tabs syncKey="biome">
      <TabItem label="npm" icon="seti:npm">
        ```sh
        npx @biomejs/biome init
        ```
      </TabItem>
      <TabItem label="pnpm" icon="pnpm">
        ```sh
        pnpm biome init
        ```
      </TabItem>
      <TabItem label="yarn" icon="seti:yarn">
        ```sh
        yarn biome init
        ```
      </TabItem>
      <TabItem label="bun" icon="bun">
        ```sh
        bunx biome init
        ```
      </TabItem>
      <TabItem label="deno" icon="deno">
        ```sh
        deno run -A npm:@biomejs/biome init
        ```
      </TabItem>
    </Tabs>

3. Enable full `.astro` HTML support and the `astro` linter domain in `biome.json`:

    ```json title="biome.json" ins={3-5,15-17}
    {
      "$schema": "./node_modules/@biomejs/biome/configuration_schema.json",
      "html": {
        "experimentalFullSupportEnabled": true
      },
      "assist": {
        "actions": {
          "source": {
            "organizeImports": "on"
          }
        }
      },
      "linter": {
        "enabled": true,
        "domains": {
          "astro": "recommended"
        },
        "rules": {
          "preset": "recommended"
        }
      }
    }
    ```

    <Aside type="tip">
    If you prefer to keep `html.experimentalFullSupportEnabled` disabled and format `.astro` files with Prettier instead, add an `overrides` block for `**/*.astro` disabling `style/useConst`, `style/useImportType`, `correctness/noUnusedVariables`, and `correctness/noUnusedImports` so template usages don't trigger false positives.
    </Aside>

4. Run Biome's CLI to lint & format your project's files:

    <Tabs syncKey="biome">
        <TabItem label="npm" icon="seti:npm">
          ```sh
          npx @biomejs/biome check --write .
          ```
        </TabItem>
        <TabItem label="pnpm" icon="pnpm">
          ```sh
          pnpm biome check --write .
          ```
        </TabItem>
        <TabItem label="yarn" icon="seti:yarn">
          ```sh
          yarn biome check --write .
          ```
        </TabItem>
        <TabItem label="bun" icon="bun">
          ```sh
          bunx biome check --write .
          ```
        </TabItem>
        <TabItem label="deno" icon="deno">
          ```sh
          deno run -A npm:@biomejs/biome check --write .
          ```
        </TabItem>
      </Tabs>
</Steps>

<Aside>
In case of an existing configuration for ESLint and Prettier, you might want to read Biome's guide for [Migrate from ESLint and Prettier](https://biomejs.dev/guides/migrate-eslint-prettier/)
</Aside>


## Adding package.json scripts

You can use Biome CLI with your preferred package manager by adding the following scripts in `package.json` of your project's directory:

```json title="package.json" ins={3-4}
{
  "scripts": {
    "lint": "biome check .",
    "lint:fix": "biome check --write ."
  }
}
```
