# Astro Tips

This is a community-driven collection of recipes, quick tips, and external community resources that complements [Astro Docs](https://docs.astro.build).

## How to help

1. Read our [Contributing guide](https://astro-tips.dev/contributing) to decide whether your content belongs in Astro Tips or official Astro Docs
2. Make an issue if you have an idea for a tip or have found a useful resource you think would help others
3. Close an issue with a PR
4. [Join the Discord](https://chat.astrolicious.dev/)

## Astro Tips vs. Official Astro Docs

Not sure whether to contribute here or to [Astro Docs recipes](https://docs.astro.build/en/recipes/)? If a solution is broadly useful, consider proposing it to official Astro Docs first—if it is too specific to maintain there, Astro Tips is a great home for it.

- **Contribute to [official Astro Docs](https://contribute.docs.astro.build/guides/recipe-writing/)** for short, focused, single-task how-to recipes built around core Astro features, widely used tooling, or common setup gotchas that fit Astro's long-term maintained and translated docs, as well as core API/concept docs and [Astro + X guides](https://contribute.docs.astro.build/guides/new-third-party-guide/) for popular, actively maintained third-party services.
- **Contribute to Astro Tips** for:
  - **Recipes** (`src/content/docs/recipes/`): in-depth, opinionated, advanced, niche, or experimental step-by-step guides (optionally with runnable projects in `examples/`).
  - **Tips** (`src/content/docs/tips/`): quick tips, patterns, workarounds, and environment- or stack-specific setups for third-party libraries or tooling.
  - **External resources** (`src/content/resources.json`): links to community blog posts, tutorials, and guides hosted elsewhere—including Astro guides for newer tools or services.
- **Contribute to a package's official docs** if the content only covers general library usage without Astro-specific details.

See the full [Contributing guide](https://astro-tips.dev/contributing) for more details.

## Goals

- Provide best practice solutions to common problems related to building sites with Astro
- Provide in-depth recipes where they are warranted
- Provide quick tips where they are warranted

## Non-goals

- Replace Astro Docs or a package's official resources
- Provide incomplete solutions
